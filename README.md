# 凌云起飞 · Takeoff Symphony

> **线上地址：https://yjj0339.github.io/takeoff-symphony/**（手机可直接打开，建议横竖屏都试试）

![二维码](qr-live.png)

凌云航空 B-2026 宽体客机的**完整起飞全程**实时三维演出：
登机准备 → 推出滑行 → 对正跑道 → 全推力滑跑 → 抬轮离地 → 收起落架 → 穿云爬升 → 转弯 → 云上巡航。

## 看点什么

- **Blender 精细建模客机**：放样机身/后掠翼/翼梢小翼、22 叶风扇涡扇发动机（低速见叶片、高速切模糊盘）、
  前双轮+主四轮小车起落架（可收放、轮子自转、bogie 俯仰）、襟翼/缝翼/扰流板逐段联动、
  曲面驾驶舱风挡、全套航行灯（防撞灯双闪/翼尖频闪/着陆灯）、天线皮托管细节、
  4096×2048 手绘风涂装（天青飘带+凌云垂尾+B-2026）
- **整座机场**：2.26km 跑道全套几何标线（中线/threshold/接地带/36·18 号码）、
  边灯进近灯 PAPI、滑行道黄色中线、停机坪站位、航站楼幕墙、廊桥×3、塔台、地勤车辆、风向袋、
  树带/农田/河流/远山地形
- **剧场式运镜**：15 个自动导播机位按时间轴切换（停机坪/廊桥/塔台长焦/跑道仰拍/离地追踪/穿云/云上远眺），
  也可手动切换 8 机位或自由环绕
- **WebAudio 合成引擎声**：锯齿 buzzsaw + 风扇宽噪 + 喷流 + 地面隆隆 + 风噪，全部实时合成零音频文件
- **中文浅色 HUD**：阶段中英文、空速/高度/N1 数据卡、可拖动时间轴（任意时刻纯函数求值）
- **穿云瞬间**：经过 330m 云层时白幕拂面，穿出即见云海在脚下

## 操作

| 按钮 | 功能 |
|---|---|
| ▶ 开始起飞 | 开始演出（含声音） |
| ⏸ / ▶ | 暂停 / 继续 |
| ↺ | 从头再飞 |
| 🔊 / 🔇 | 声音开关 |

## 技术

纯前端 three.js 0.170（无构建步骤），模型由 Blender 5.2 无头脚本生成（`blender/` 目录），
贴图由 PIL 程序化绘制（`blender/make_textures.py`）。GLB 双文件约 1.6MB。

```bash
node tools/server.js 5173   # 本地预览 http://localhost:5173
python blender/make_textures.py   # 重新生成贴图
blender --background --python blender/build_plane.py    # 重新建模飞机
blender --background --python blender/build_airport.py  # 重新建模机场
node tools/test_app.js       # 整场演出静默截图
```
